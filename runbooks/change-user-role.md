# Runbook — Change Workforce Role

1. Identify the employee's current and target team.
2. Change corporate group membership rather than assigning permissions directly to the user.
3. Wait for the identity/assignment change to become effective.
4. Verify the old permission path is no longer available.
5. Verify the new permission path works.
6. Run one negative test against a privilege that should remain denied.
7. Record evidence and audit activity.
