# Runbook — Onboard Workforce User

1. Create or enable the employee in the corporate directory.
2. Place the employee in the correct workforce group.
3. Allow identity synchronization/integration to complete.
4. Verify the expected IAM Identity Center assignment.
5. Require/verify MFA according to the selected identity-source design.
6. Test AWS access portal login.
7. Test one allowed AWS action.
8. Test one intentionally denied action.
9. Record evidence and audit event.

Do not create an employee-specific long-lived AWS access key as part of normal onboarding.
